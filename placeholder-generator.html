Placeholder Image Generator

Use this tool to generate placeholder images for development. Replace these with actual product images later.

Instructions:

  1. Enter the text you want on the placeholder
  2. Adjust width and height as needed
  3. Choose background and text colors
  4. Click "Generate" to preview
  5. Click "Download PNG" to save the image
  6. Save the image to the appropriate folder (e.g., images/products/)

Recommended Sizes:

  • Product Cards: 400x400 pixels
  • Gallery: 800x600 pixels
  • Hero Section: 1200x600 pixels
  • Favicon: 64x64 pixels
